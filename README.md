# 📊 Sales Analytics — Análise de Vendas

## Sobre o projeto

Projeto de análise de vendas desenvolvido para praticar modelagem de banco de dados, consultas SQL, tratamento de dados e visualização de indicadores comerciais.

O objetivo é transformar dados de vendas em informações que auxiliem na tomada de decisões.

## Tecnologias utilizadas

- **MySQL:** criação e estruturação do banco de dados.
- **SQL:** consultas, relacionamentos e extração de informações.
- **Excel:** tratamento dos dados, indicadores e desenvolvimento do dashboard.

## Arquivos do projeto

| Arquivo | Descrição |
|---|---|
| `sales_analytics.sql` | Script SQL do banco de dados |
| `sales_analytics_vendas_limpas.csv` | Base de vendas tratada |
| `Painel de Análise de Vendas.xlsx` | Dashboard em Excel |
| `Painel de Análise de Vendas.pdf` | Dashboard em PDF |
| `Análise de Vendas_Vendas.pdf` | Relatório detalhado das vendas |

## Indicadores analisados

- Faturamento total
- Quantidade de vendas
- Unidades vendidas
- Ticket médio
- Desempenho por categoria, produto e loja

## Resultados

- **Faturamento total:** R$ 40.425,80
- **Vendas únicas:** 20
- **Unidades vendidas:** 42
- **Ticket médio:** R$ 2.021,29

## Tratamento dos dados

Foram identificados 20 registros duplicados em uma exportação de 40 linhas. Após a deduplicação, foram mantidas 20 transações únicas.

A limpeza foi aplicada à base utilizada na análise, preservando o banco de dados MySQL original.

## Observações

Os dados utilizados são fictícios e destinados a fins educacionais e de portfólio.
